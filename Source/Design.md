# Interface design

Visual thesis: a calm native macOS workspace with a large file queue, a compact settings inspector, and one violet action color.

Content plan: file import and selection in the primary workspace; format, destination, and export controls in the inspector; status and size comparisons alongside each file.

Interaction thesis: highlight the workspace when files are dragged over it; animate conversion progress; use a focused sheet for playback. System controls respect the user's appearance and accessibility settings.
